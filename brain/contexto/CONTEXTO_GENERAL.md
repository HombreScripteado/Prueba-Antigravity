# 📋 Contexto General del Proyecto

## Proyecto: Menu AR Web4

**Estado**: En desarrollo  
**Stack**: Next.js, TypeScript, Vercel  
**Objetivo**: Aplicación web interactiva para menú AR

---

## 📌 Información Clave

### Estructura
- **Frontend**: Next.js (TypeScript)
- **Ruta de app**: `v0-interactive-menu-website-main/app`
- **Páginas dinámicas**: `[category]/page.tsx`

### Decisiones Arquitectónicas
- Usar App Router de Next.js
- TypeScript para type safety
- Dynamic routes para categorías

### Restricciones (INVIOLABLES)
- ⚠️ **MODULARIDAD**: 100% personalizable por cliente
- ⚠️ **COMPATIBILIDAD**: Ningún cambio rompe clientes existentes
- ⚠️ **NO DESTRUCTIVOS**: Sin modificaciones a core existente
- Performance crítica para experiencia mobile
- Mantener compatibilidad con AR features
